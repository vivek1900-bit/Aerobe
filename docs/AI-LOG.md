# AI-Generated Assets Log

Aerobe is a hand-built React + Three.js application. During design, a few AI-generated visual assets were produced as reference or evaluated for inclusion. None of them are required at runtime — the shipped app renders the bioreactor in code.

## Visual assets

| Asset | Tool | Used in final app? |
|---|---|---|
| Cinematic reactor video (`hf_20261025_091603_fd4115d3-0036-400c-9ca7-358375e3d35e.mp4`) | **Higgsfield** (higgsfield.ai) | No — evaluated for the tour hero, then reverted; the tour renders the reactor with live WebGL. |
| Dashboard concept image (`dashboard_…_Gemini_Generated_Image_….png`) | **Google Gemini** (Imagen) | No — used only as a visual reference for the Obsidian Bento console layout. |
| Console UI exports (`stitch_aerobe_bioreactor_console.zip`) | **Stitch** (stitch.withgoogle.com) | No — reference for the console / analytics / report screen design. |

## Notes
- The production 3D reactor uses procedural materials (borosilicate glass, 316L steel, amber broth) and code-generated studio lighting — no AI imagery.
- All AI-generated assets are illustrative reference only and carry no claim of real-world validation.
