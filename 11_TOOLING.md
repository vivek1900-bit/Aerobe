# 11 - Tooling (v2)
**One coding assistant is enough** (Gemini, Claude or ChatGPT in the browser). Paste `00_START_HERE.md` first, then the spec file(s) for the current step, then say: "I am Person X, step S-xx." OpenCode and Antigravity are optional conveniences, not review roles, required tools, or sources of technical claims.
- **Editor:** VS Code. Terminal inside VS Code.
- **Rules file:** copy `templates/AGENTS.md` to the repo root if you use any coding agent that reads it.
- **Optional:** terminal agents or agent IDEs are allowed but not required; do not spend setup time on them before Tier 1 is done.
- **Local models:** not needed.
- **Prompts:** `prompts/PROMPTS_V2.md`. Paste one at a time; verify before the next.
- **Commands you will use:** `npm run dev`, `npm run build`, `npm test`, `npx vercel dev`, `git status`, `git add -A && git commit -m "..."`, `git push`.
- **Screenshots:** when asking for visual fixes, include 1440x900 and 390x844 screenshots and the console errors.
