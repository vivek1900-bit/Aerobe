# 08 — Optional 3D bonus

This file is intentionally not a build specification for the required submission. The required reactor is `ReactorSVG`; it must already respond to controls and work in lite mode, reduced motion, and on the live Vercel URL.

## Start condition

3D work may begin only when every 03 §5 / 12 §1 gate is green, the public URL/video/repository are ready, and the team has confirmed time remains before the deadline. The confirmed deadline is **Sun 25 Oct 2026, 5:00 PM IST**.

## Optional scope

An R3F reactor, exploded view, interior/dive view, bloom, and decorative shaders are optional polish. They must never replace the SVG reactor, block Skip/deep links, add a required dependency to lite mode, delay submission, or weaken accessibility.

## Safety rules

- Test each optional package in the actual project before committing it; if it fails, omit it.
- Use the same named reactor-part contract as `ReactorSVG`.
- Preserve the illustrative teaching labels and deterministic simulation boundary.
- If performance drops, disable the 3D path and retain the SVG console.
